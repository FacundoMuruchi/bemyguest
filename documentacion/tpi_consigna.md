# Trabajo Práctico Integrador – Ingeniería de Datos II

# Profesora: Dra. Ing. Roxana Martínez

**Objetivo**

El presente trabajo tiene como finalidad que los estudiantes diseñen y desarrollen un
proyecto integral que permita aplicar, de manera práctica, los conocimientos adquiridos
en la asignatura. Se busca que puedan integrar herramientas, lenguajes y tecnologías de
bases de datos NoSQL en un contexto de solución a un problema real o una oportunidad
de negocio.

**Consigna general**

Deberán proponer y desarrollar un proyecto original basado en una idea de negocio, en
el cual se evidencie el uso de tecnologías de almacenamiento y procesamiento de datos.

El proyecto deberá contemplar:

```
▪ El uso de un lenguaje de programación a elección (preferentemente Python,
aunque también puede ser Java u otro con el que se sientan cómodos).
▪ La integración y uso de una base de datos orientada a grafos ( Neo4j ).
▪ La integración y uso de una base de datos NoSQL orientada a documentos
( MongoDB ).
▪ La integración y uso de una base de datos NoSQL orientada a columnas (Apache
Cassandra ), evidenciando su aplicación en escenarios que requieran alta
escalabilidad y manejo eficiente de grandes volúmenes de datos.
▪ La integración y uso de una base de datos en memoria ( Redis ), demostrando su
utilización en casos de caching, optimización de tiempos de respuesta o manejo
de datos en tiempo real.
▪ La implementación de mecanismos de conexión, interacción y manipulación de
datos entre la aplicación desarrollada y ambas bases de datos.
```
Se evaluarán las habilidades de BASES DE DATOS, no así de PROGRAMACIÓN.

```
No está permitido utilizar un software de otra asignatura.
```

**Requisitos específicos**

_El proyecto deberá:_

1. Presentar una idea de negocio clara, fundamentada y viable la cual deberá ser
aprobada por la docente.
2. Justificar el uso de cada tipo de base de datos en función del problema planteado.
3. Demostrar la correcta implementación de:
    - Modelado de datos en MongoDB.
    - Modelado de grafos en Neo4j.
    - Modelado de grafos en Redis.
    - Modelado de grafos en Cassandra.
4. Incluir operaciones básicas y avanzadas (consultas, inserciones, actualizaciones,
relaciones, etc.), vistas en clase.
5. Evidenciar la interacción entre la aplicación desarrollada y ambas bases de datos.
Destacando las bases de datos.
6. Mostrar buenas prácticas de base de datos (claridad, documentación básica, etc).

**Entregables**

- Documento descriptivo del proyecto (portada, idea de negocio, justificación
    tecnológica, arquitectura propuesta, etc.).
- Código fuente inicial más bases de datos.
- Evidencia de conexión e interacción con ambas bases de datos.
- Ejemplos de consultas y operaciones realizadas.

**Importante**

En dicha etapa se profundizará y ampliará el desarrollo realizado en esta primera
entrega, incorporando nuevos requerimientos y mejoras sobre la solución propuesta.


**Criterios de evaluación**

Se tendrá en cuenta:

- Originalidad y claridad de la propuesta.
- Correcta aplicación de conceptos teóricos.
- Uso adecuado de las tecnologías requeridas.
- Calidad técnica de la implementación.
- Coherencia entre la solución planteada y la necesidad de negocio.

_Se espera que este trabajo les permita explorar, experimentar y consolidar habilidades
clave en el ámbito de la ingeniería de datos, promoviendo tanto la creatividad como el
pensamiento crítico._
